## 한국어 남은 범위

이번 증분은 읽기/필터/다중 항목/이력·차이/명시 저장·재시작/일반 필드 편집/비활성화와 개인 오버레이 확장을 구현합니다. 위 표의 단위 검사와 합성 Chrome 검사는 현재 소스 경로의 근거이며 실제 확장·실사이트 성공은 아닙니다.

여전히 구현되지 않은 유용한 이전 기능은 네이티브 포인터·호버·드래그·키/클립보드, 네이티브 영역 휠 라우팅, 검색 제출·도착 조건 대기, 다중 관찰의 문서 축적·내보내기 manifest, fingerprint 재결합, 녹화형 절차 및 형식 이전입니다. 렌더/픽셀/ASCII/quad/frame 실험은 별도 연구 행으로 남깁니다. 원본 소스가 없는 Sakaba/gen3의 전체 비교도 미확인입니다.

브라우저 확장 설치/Origin/activeTab/MV3 수명, 전경 UI·키보드 접근성, 실제 사이트 읽기·탐색 유용성, 특정 MCP 클라이언트와 비Windows 지원은 감독자 실측이 필요합니다. 이 검증 차단 때문에 위의 독립 구현을 중단하거나 미검증 기능을 통과로 바꾸지 않습니다.
