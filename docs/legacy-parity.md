## 한국어 남은 범위

현재0.5는0.2의 필터/다중 항목/이력·차이/명시 저장과 개인 오버레이,0.3의 한 번 탐색 후 도착 검사·명시 누적 문서,0.4의 전역 pause·보존형 pack archive/restore 위에 제한된 현재 컨테이너 pageRead를 연결합니다. 활성/effective 판본·유일한 스크롤 역할·선택 읽기·출처/범위·측정된 진행·입력 영수증을 횟수/시간/내용 한도 안에서 보존합니다. native wheel·자동 저장·전체 완독은 아닙니다. 감독자가 최종 소스로 전체81개 검사를 다시 실행해 모두 통과했습니다. 성공 스크롤의 실제 변위·후속 관측 좌표 일치도 합성 Chrome에서 확인했습니다. 실제 확장·실사이트 성공은 주장하지 않습니다.

여전히 구현되지 않은 유용한 이전 기능은 네이티브 포인터·호버·드래그·키/클립보드, 네이티브 영역 휠 라우팅, 네이티브 검색 제출, 자동 페이지 관찰 축적·고정 경로 갱신, fingerprint 재결합, 녹화형 절차 및 형식 이전입니다. 렌더/픽셀/ASCII/quad/frame 실험은 별도 연구 행으로 남깁니다. 원본 소스가 없는 Sakaba/gen3의 전체 비교도 미확인입니다.

브라우저 확장 설치/Origin/activeTab/MV3 수명, 전경 UI·키보드 접근성, 실제 사이트 읽기·탐색 유용성, 특정 MCP 클라이언트와 비Windows 지원은 감독자 실측이 필요합니다. 이 검증 차단 때문에 위의 독립 구현을 중단하거나 미검증 기능을 통과로 바꾸지 않습니다.

## 0.3.0 inheritance update

Navigation now adds exact same-origin href arrival plus observed destination conditions after one attempt, with count/time/cancel/binding bounds and separate delivery/arrival evidence. It does not implement native Enter/query submission, allowed-query omission/redirects, cross-origin grants or Nomiya native paint currentness. Explicit accumulated documents now preserve compatible saved reading sections, expected revisions/idempotent append, restart, bounded escaped Markdown/metadata export and integrity manifests. They do not implement automatic PageObservation merging, full-page read loops, replacement/gap inference or fixed-path refresh publication. See navigation-and-documents.md and the exhaustive catalog-level legacy-api-inventory.md; the table above distinguishes new limited counterparts from the remaining original behavior.
